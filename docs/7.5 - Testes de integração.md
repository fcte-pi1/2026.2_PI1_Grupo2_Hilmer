# Testes de Integração

Confiram as regras de avaliação dos testes de integração no [documento do tema do projeto](https://docs.google.com/presentation/d/1hRx0g9mpVGQbTv44gLEoAyf4b4kKM4vnrABTnG8HlUk/edit?usp=sharing).

Testes feitos com o robô montado (chassi, bateria LiPo 2S, ponte H L298N, motores N20 com encoder, três VL53L0X, MPU6050, INA219 e ESP32), usando os exemplos de `src/firmware/src/exemplos/`. Cada teste indica o exemplo usado, e o registro de cada corrida fica gravado na flash do ESP32 e é lido depois pela USB (comando `r` do `exemplo_explorar`).
