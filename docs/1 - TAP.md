# Termo de Abertura do Projeto

## Visão Geral do Projeto

### Dados do projeto

- **Nome do Projeto: MicroMouse Grupo 2**

- **Data de Término: 04/12/2026**
- **Patrocinador:** Universidade de Brasília


### Objetivos

Desenvolver, integrar e validar, até o término do segundo semestre letivo de 2026, um sistema micromouse autônomo capaz de navegar e concluir os três tipos de labirintos propostos (4×4, 8×4 e 12×4 células) sem intervenção humana durante a execução, identificando paredes, monitorando sua localização, mapeando o percurso e reconhecendo a chegada ao objetivo. O sistema deverá ainda disponibilizar, em tempo real, dados de telemetria por meio de uma aplicação web e armazenar os resultados obtidos em banco de dados para consultas posteriores, atendendo às restrições físicas e operacionais estabelecidas para o projeto.

### Público-Alvo

O público-alvo do projeto é composto principalmente por estudantes, professores, pesquisadores e instituições de ensino envolvidos com engenharia, robótica, automação, sistemas embarcados e áreas correlatas. O sistema desenvolvido também pode servir como plataforma didática para atividades de ensino, pesquisa e extensão relacionadas à integração de conhecimentos de estruturas, eletrônica, energia, hardware, software, controle e desenvolvimento de sistemas autônomos. De forma indireta, os resultados do projeto também podem beneficiar equipes e grupos acadêmicos envolvidos em competições e projetos de robótica móvel. 


### Descrição do Problema

O projeto surge da necessidade de desenvolver uma solução integrada de engenharia capaz de realizar navegação autônoma em ambientes previamente desconhecidos. Para cumprir a tarefa proposta, o sistema deverá identificar obstáculos e paredes, determinar sua própria localização, construir uma representação do labirinto, definir um percurso e reconhecer a chegada ao destino sem intervenção humana durante a execução. Além da navegação, existe a necessidade de monitorar o desempenho do sistema por meio da aquisição, transmissão, visualização e armazenamento de dados de telemetria. Dessa forma, o projeto propõe a integração de conhecimentos das diferentes áreas de engenharia da FCTE na concepção e validação de um sistema robótico autônomo funcional.
